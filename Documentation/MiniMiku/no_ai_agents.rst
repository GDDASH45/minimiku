MiniMiku Kernel AI Agent Policy
===============================

Overview
--------

MiniMiku maintains its own kernel features and modifications on top of
the Linux kernel.

This document defines the project's policy regarding contributions
generated or submitted by AI agents.

Policy
------

AI agents must not independently submit, commit, or push changes to
the MiniMiku kernel repository.

All kernel modifications must be reviewed and explicitly approved by
a human maintainer before they are merged into the project.

Human Responsibility
--------------------

Contributors are responsible for understanding the code they submit,
including code initially drafted with AI assistance.

Kernel changes must be reviewed for correctness, security, stability,
and compatibility with the Linux kernel build system.

Scope
-----

This policy applies to AI agents operating autonomously on the
MiniMiku kernel repository. It does not prohibit human developers
from using AI-assisted tools while developing or reviewing code.

Enforcement
-----------

Maintainers may reject contributions that violate this policy or
that have not received the required human review.
